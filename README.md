# Лабораторна робота (Dart) - варіант 1: Погодний щоденник міст

Консольний застосунок: список записів про погоду в містах, додавання, видалення,
збереження у `data.json` та відновлення під час наступного запуску.

## Запуск
1. Встановити Dart SDK 3.0 або новіший (`dart --version` має працювати в терміналі).
2. Клонувати репозиторій і перейти в його теку:
   `git clone https://github.com/7804321www/lab_dart1.git`
   `cd lab_dart1`
3. Запустити програму: `dart run bin/main.dart`.

Зовнішні пакети не потрібні, тому `dart pub get` виконувати необов’язково.

Дані зберігаються у файлі `data.json`, який програма створює сама після додавання першого запису. Якщо в консолі Windows замість українських літер відображаються спотворені символи, виконайте `chcp 65001` і запустіть програму знову.

## Структура
- `bin/main.dart` - точка входу, текстове меню
- `lib/models/weather_entry.dart` - модель, `toJson()` / `fromJson()` / `toString()`
- `lib/repositories/entry_repository.dart` - читання/запис `data.json`

## API варіанта: Open-Meteo (у цій версії не використовується)
https://api.open-meteo.com/v1/forecast?latitude=50.75&longitude=25.34&current=temperature_2m
